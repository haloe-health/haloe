haloe email logo generator

Regenerates images/email-logo@2x.png — the flower icon + "haloe" wordmark lock-up baked into a single PNG on a cream rounded-pill background, used by functions/_email.js's emailHeader() in every transactional email.

Reads ../haloe-logo-flower.svg (never edited) and ../fonts/TAN-ASHFORD.woff2 as-is. Open this file through the local dev server (http://localhost:8788/tools/email-logo-generator.html) so both relative paths resolve — opening it directly from disk (file://) won't fetch the SVG.

Target proportions

  • Icon height = the wordmark's own ascender-top-to-baseline span (measured live via canvas TextMetrics.actualBoundingBoxAscent on the string "haloe" in Tan Ashford — this font's ascenders overshoot its own em-box, so this is not a fixed em multiple of a "normal" font; it's re-measured every time this page runs).
  • Icon vertically centred on that same span (its top sits at the ascender-top, its bottom at the baseline).
  • Gap between icon and wordmark = the measured width of the letter "a" in the same font/size.
  • Cream (#F5F0E8) rounded-pill background baked into the raster, ~24px padding at 1x, exported at 2x for retina.
